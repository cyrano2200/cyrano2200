## First project

**[Jarvis](https://github.com/cyrano2200/jarvis)** is a local AI voice assistant, and the first project I built.

Wake it with **Hey Jarvis**. Speech and routing run on the machine. The model is local (Ollama or LM Studio), with an optional cloud fallback. Tools cover apps, files, the system, the web, notes, timers, and media. Destructive actions ask for confirmation.
